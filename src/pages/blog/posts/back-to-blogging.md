## แนะนำตัวสั้นๆ

สวัสดีครับ ผมชื่อต๊อปครับ ผมเป็นวิศวกรซอฟต์แวร์ธรรมดาๆคนหนึ่งที่ใช้ชีวิตแบบขี้เกียจไปวันๆ ชีวิตค่อนข้างเรียบง่าย ไม่กดดันตัวเองหรือตั้งเป้าหมายอะไรให้วุ่นวาย ถ้าถามว่าชอบอะไร ตอนนี้ตอบไม่ได้จริงๆ แม้จะดูเป็นคำถามง่ายๆก็ตาม

เมื่อก่อนชอบตั้งเป้าหมายระยะสั้นให้ตัวเอง มีแรงผลักดันทำโน่นทำนี่ โดยเฉพาะเรื่องการเขียนโปรแกรม ชอบแก้ปัญหาและสร้างเว็บไซต์หรือแอปพลิเคชันต่างๆ เพื่อช่วยแก้ปัญหาหรือทำให้งานที่ต้องทำซ้ำๆเป็นระบบอัตโนมัติ แม้จะสำเร็จบ้างล้มเหลวบ้าง แต่ไม่รู้ทำไม ตอนนี้รู้สึกเหมือนหมดไฟ หาแรงบันดาลใจไม่เจอ อาจเป็นเพราะลักษณะงานที่ทำ ทำให้ทักษะทางเทคนิคในการเขียนโปรแกรมลดลงไปเยอะ จนรู้สึกเฉยๆกับมันไปแล้ว

ผมชอบความเรียบง่าย ไม่หลงใหลอะไรเป็นพิเศษ ไม่เล่นเกม (แม้จะมี PS5 ไว้เล่น FC และกำลังเก็บเงินซื้อ PC มาเล่นกับทำโปรเจกต์) ไม่อ่านการ์ตูน ดูหนังบ้างถ้ารู้สึกว่าน่าสนใจ แต่ก็น้อยมากเมื่อเทียบกับค่า Netflix และ Disney Plus ที่จ่ายไปทุกเดือน เมื่อก่อนดูซีรีส์ทางฝั่งอเมริกาและอังกฤษเยอะมาก เพราะมีเวลา

การแต่งตัวก็ธรรมดา แค่เสื้อยืดกับกางเกงขาสั้นหรือยีนส์ไปทำงาน ใช้มือถือรุ่นเก่า คอมพิวเตอร์ก็ใช้มาหลายปี (แต่ทั้งสองอย่างกำลังเก็บเงินซื้อใหม่แล้ว เพราะเครื่องเก่าเริ่มทำงานไม่ค่อยได้) แต่ถ้าเป็นเรื่องกิน เที่ยว ดื่ม ใช้เงินปกติเหมือนผู้ชายทั่วไป

เดินทางด้วยรถไฟฟ้าเป็นหลัก สลับกับ Grab bike ถ้าต้องต่อหลายสาย เพราะไม่อยากเสียเวลากับรถติด ยังไม่มีรถยนต์เป็นของตัวเอง ใช้ของที่บ้านถ้าต้องออกไปแถวๆบ้าน เพราะที่บ้านมีหลายคันอยู่แล้ว และยังไม่อยากสร้างภาระทางการเงินในตอนนี้

เครื่องดื่มที่ชอบมีสามอย่าง: ชาเขียว, กาแฟอเมริกาโน่ไม่หวานที่ดื่มเพื่อให้ตื่น (แม้จะไม่ได้รู้เรื่องกาแฟอะไรมากมาย) และโอวัลตินเย็นจากรถเข็นที่รสชาติอร่อยดีจริงๆ

เท่าที่จำความได้ เขียนบล็อกล่าสุดเมื่อปี พ.ศ. 2561 (2018) ซึ่งส่วนใหญ่จะเกี่ยวกับ coding และการอธิบาย syntax ใน programming ต่างๆ ไม่ค่อยได้มาเล่าเรื่องหรือบ่นเรื่องชีวิตในนี้สักเท่าไร แต่หลังจากนี้จะพยายามกลับมาเขียนบล็อกมากขึ้น เพื่อทบทวนว่าปีที่ผ่านมาทำอะไรบ้าง เหมือนบันทึกความทรงจำในสิ่งที่เจอมา

ทั้งหมดนี้คือเรื่องราวคร่าวๆของผม แต่สิ่งที่ทำให้ต้องกลับมาเขียนบล็อกอีกครั้งมีเหตุผลที่น่าสนใจ

## ทำไมผมถึงกลับมาเขียนบล็อก?

เหตุผลหลักคือรู้สึกว่าภาษาไทยถดถอยและเริ่มพูดไม่รู้เรื่องขึ้นทุกวัน กลัวว่าจะมีปัญหาการสื่อสารหรือการอธิบายสิ่งต่างๆ ลามไปจนถึงการเขียนและการสื่อสารในงาน เป็นคนอ่านหนังสือน้อย ไม่รักการอ่าน (เพราะขี้เกียจ) ยกเว้นเอกสารทาง technical ที่ใช้ในงาน แต่มันก็ทับศัพท์ภาษาอังกฤษเยอะ เลยอยากใช้ช่องทางนี้ถ่ายทอดความคิดเพื่อพัฒนาทักษะการเขียนภาษาไทย

## ทำไมผมถึงสร้างบล็อกใหม่?

อยากท้าทายตัวเองให้ก้าวออกจาก comfort zone แบบเดิมๆ เนื่องจากไม่ได้เขียน code จริงจังประมาณ 2 ปีแล้ว เลยลองเล่น web framework ใหม่ชื่อ Astro เป็นการฝึกฝนไปในตัว

เลือกใช้ Astro เพราะมันออกแบบมาสำหรับเว็บไซต์ที่เน้นเนื้อหาเป็นหลัก (content-focused websites) ที่ผ่านมาเคยแต่เขียน React กับ NextJS ซึ่งเหมาะกับเว็บที่ต้องโต้ตอบกับผู้ใช้งานเยอะ แต่สำหรับบล็อกที่เน้นเนื้อหาอย่างเดียว Astro เพียงพอแล้ว เขียนง่าย โหลดเร็ว ไม่ต้องปวดหัวกับอะไรเยอะ เขียนบล็อกใน markdown file ใช้ Astro render และ host ทุกอย่างบน GitHub ไม่มีค่าใช้จ่าย
